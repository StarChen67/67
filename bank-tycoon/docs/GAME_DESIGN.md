# 銀行大亨 Bank Tycoon — 遊戲設計與公式（GAME_DESIGN）

> 所有數字都在 `config/config.js` 與 `data/*.js`，本文是它們的說明；若有出入以程式為準。
> 核心：**收益 vs 風險 vs 安全**。存款是槓桿，股票是收益，搶劫與擠兌是風險，保全與準備金是安全。

---

## 1. 初始狀態
- 現金 200,000、Lv.1 小型銀行、信用 600（BBB）、存款利率 2%、門鎖 Lv.1 + 警報器 Lv.1 + 基礎金庫 Lv.1（保護 250,000）。
- 1 遊戲日 = 2 秒（1×）；1×/2×/4×/8× 與暫停；可手動「下一天」。

## 2. 總體經濟（Economy）
景氣階段狀態機（每日轉移機率，`CONFIG.economy.phases`）：

| 階段 | 股票年化漂移修正 | 波動倍率 | 新客戶倍率 | 提款倍率 | 轉移 |
|---|---|---|---|---|---|
| normal 平穩 | 0 | 1.0 | 1.0 | 1.0 | →boom 1%/日、→recession 0.8%/日 |
| boom 繁榮 | +0.10 | 0.9 | 1.3 | 0.9 | →normal 3%/日 |
| recession 衰退 | −0.15 | 1.3 | 0.75 | 1.3 | →normal 3%/日、→crisis 1%/日 |
| crisis 金融危機 | −0.35 | 1.8 | 0.5 | 1.8 | →recession 5%/日 |

- 市場基準利率 `marketRate`：每日 `r += 0.02×(0.020 − r) + N(0, 0.0004)`，夾在 [0.5%, 10%]；事件「利率上升/下降」直接 ±。
- 通膨 `inflation`（%）：每日 `inflation *= (1 − 0.02)`；印鈔增加。
  - `costMult = 1 + inflation/100`（升級、保全購買、維護、營運費、印鈔機升級）
  - `demandedRate = marketRate × (1 + inflation/50)`（客戶期望的存款利率）
  - 股票波動 `× (1 + inflation/100)`
- 閒置現金有準備金利息：`marketRate × 0.9`，低於存款成本，所以完全不投資仍會慢慢虧。

## 3. 客戶與存款（Customers / Deposits）

### 3.1 客戶類型（`data/customers.js`）

| 類型 | 解鎖 | 初始餘額 | 單次存款 | 存款機率/日 | 提款機率/日 | 提款比例 | 信用要求 |
|---|---|---|---|---|---|---|---|
| retail 散戶 | Lv1 | 3,000–40,000 | 800–6,000 | 6% | 4% | 10%–50% | 無 |
| small_biz 小商家 | Lv2 | 30,000–40.0萬 | 12,000–12.0萬 | 8% | 7% | 20%–60% | 360 |
| vip 貴賓 | Lv3 | 30.0萬–500.0萬 | 70,000–75.0萬 | 4% | 3% | 10%–40% | 480 |
| corp 企業 | Lv5 | 300.0萬–6000萬 | 180.0萬–2000萬 | 5% | 5% | 20%–70% | 600 |
| inst 機構 | Lv7 | 5000萬–8.00億 | 3000萬–4.00億 | 3% | 3% | 30%–80% | 700 |

金額為對數均勻分布。每個等級有自己的類型權重（見 §8）。

### 3.2 吸引力與新客戶

```
rateFactor   = clamp(0.3 + 0.7 × depositRate / demandedRate, 0.3, 2.5)
creditFactor = {AAA:1.4, AA:1.25, A:1.1, BBB:1.0, BB:0.8, B:0.6, CCC:0.35, D:0.15}[rating]
safetyFactor = 1 − risk/200
panicFactor  = 1 − 0.9 × panic/100
attract      = rateFactor × creditFactor × safetyFactor × panicFactor × phase.arrivalMult × events.mod('arrivalMult')
fill         = min(1 − count/level.maxCustomers, 1 − deposits/(netWorth × level.maxLeverage))
lambda       = level.arrivals × attract × fill        // 資本槓桿上限也會擋住新存款
新客戶數 ~ Poisson(lambda)
```

### 3.3 每位客戶每日

```
存款：機率 type.pDeposit × sqrt(rateFactor) × phase.arrivalMult × (1 − panic/100)；金額 ~ type.depositRange
提款：機率 type.pWithdraw × (1 + panic/25) × phase.withdrawMult × events.mod('withdrawMult')
      × (rate < 0.5×demanded ? 1.5 : 1)；金額 = balance × U(type.withdrawFrac)
離開：機率 0.2% × (1 + panic/20) × (信用低於門檻 ? 5 : 1) × (rate < 0.4×demanded ? 3 : 1) → 全額提款並移除
擠兌（panic ≥ 70 觸發，< 40 結束）：提款機率 35%、比例 50–100%
恐慌 panic：每日 −3（信用 ≥ A 時 −5）；搶劫成功 +10 + 40×loot/cash；逾期未付 +5/日；危機事件 +15；
            可花錢「穩定信心」−20
```

### 3.4 利息

```
每日 payable += Σ balance × depositRate / 365
每 30 天付息日：charge(payable, 'interest', 期限 7 天) → 現金流出
```

### 3.5 待付義務（Treasury）
- 任何 `charge()` 付不出的部分進入 `obligations`（提款期限 5 天、利息 7 天、其他 10 天）。
- 每日 FIFO 結清；存在逾期義務：信用 −25/日、恐慌 +5/日。
- 緊急貸款：額度 = `level.loanCap`，日利率 0.05%（年化約 18%），最多 2 筆，可隨時償還。

## 4. 股票（Stocks）

每支股票：`{ id, code, name, sector, tier, base, drift(年化對數), vol(日σ), rating, risk 1–5, crashP(日), crashRange, phaseDrift? }`

```
ret = (drift + phase.driftAdd + events.driftMod(sector) + phaseDrift[phase]) / 365
    + vol × phase.volMult × eventVolMult × (1 + inflation/100) × N(0,1)
    + 0.12 × momentum                  // momentum = 0.85×momentum + 0.15×ret，夾 ±0.6%
若 U < crashP × (phase==crisis ? 3 : 1)：ret −= U(crashRange)
price = max(0.5, round2(price × exp(ret)))
```

**平衡原則：扣掉崩盤損耗後的實際年化，必須隨風險星等遞增**，否則高風險股就只是陷阱。

## 5. 理財商品（Products）

公債從 Lv.1 就能買 —— 這是銀行最基本的獲利方式：用 2% 收來的存款去買 8% 的短債，賺中間的利差。
高殖利率的商品才需要更高的等級，而且帶違約風險。

到期領回 `本金 × (1 + yield × term/365)`；提前贖回 `本金 × (1 − penalty)`，已累積的利息全部沒收。

## 6. 信用評級（Credit）

```
capital   = clamp(netWorth/assets / 0.12, 0, 1)
liquidity = clamp((cash/deposits − 0.03) / 0.17, 0, 1)
profit    = clamp(0.5 + (30日淨利/netWorth) / 0.06, 0, 1)      // +3% → 1，−3% → 0
security  = 1 − risk/100
levelS    = (level−1)/7
overdue   = 有逾期義務 ? 0 : 1
target    = min(level.creditCap, 150 + 250×capital + 200×liquidity + 150×profit + 100×security + 100×levelS + 50×overdue)
score    += (target − score) × 0.08 + 衝擊
衝擊：搶劫成功 −40 −40×loot/cash；防守成功 +8；逾期 −25/日；升級 +30；事件 ±
評級：AAA ≥900、AA ≥800、A ≥700、BBB ≥600、BB ≥480、B ≥360、CCC ≥220、D
```

## 7. 印鈔機（Printer，Lv5 解鎖）

```
每次印鈔：inflation += 100 × 輸出 / max(總資產, 100萬) × 2.5 + 該級的 inflation
```

```
attackMult   = Π device.attackMult

維護費/日    = Σ device.maint × costMult + 薪資

```

## 10. 搶劫（Robbery）

```
exposure(cash)        = 分段內插：0→0, 10萬→3, 20萬→8, 50萬→25, 100萬→40, 200萬→55,
                        500萬→68, 1000萬→80, 5000萬→90, 2億→96, 10億→100
requiredDefense(cash) = 對數分段內插：20萬→12, 50萬→30, 100萬→50, 200萬→85, 500萬→150,
                        1000萬→230, 2000萬→340, 5000萬→520, 1億→750, 3億→1100, 10億→1800
coverage   = defense / requiredDefense
mitigation = 0.95 × (1 − exp(−1.6 × coverage))
risk       = clamp(exposure × (1 − mitigation) + events.mod('riskAdd'), 0, 100)
每日搶劫機率 = 0.018 × risk/100（前 10 天免疫；上次嘗試後 20 天冷卻）
```

風險分級：0–20 非常安全、21–40 低、41–60 中等、61–80 高、81–100 極高。

強盜強度隨現金規模連續成長：`attack = U(tier.attack) × clamp(1 + 0.45 × log10(cash / 100萬), 1, 6)`。
銀行越大，來的人越強 —— 保全必須跟著銀行一起長大。

```
若 U < smart.abortChance → 事前攔截，防守成功
effAttack  = attack × attackMult
pSuccess   = clamp(effAttack / (effAttack + defense), 0.03, 0.97)

// 金庫不是全有全無：攻擊力剛好超過門檻只撬得開一小部分，兩倍才整個搬空
opened     = clamp(effAttack × U(0.8,1.2) / vaultStrength − 1, 0, 1)
accessible = (cash − protectCap) + protectCap × opened

loot = min(accessible × U(tier.lootFrac), tier.maxLoot)
     × (1 − 0.5 × policeSpeed)          // 警方到得快，搬得少
     × (1 − 0.7 × mitigation)           // 保全充足，搬得少
loot = min(loot, cash, 淨資產 × 0.40)    // 單次搶劫不得超過淨資產四成

成功：cash −= loot；恐慌 += (10 + 40×loot/cash) × panicMult；
      信用 −(40 + 40×loot/cash) × panicMult；1–2 個設備耐久 −10～40%；保全受傷；保險理賠
失敗：信用 +8、XP +50、35% 機率有設備輕微受損
```

|---|---|---|---|---|

## 12. 破產（Bankruptcy）

任一成立即倒閉：
1. 任何待付義務逾期超過寬限（提款 5 天、利息 7 天）仍付不出。
2. 淨資產 < 0 連續 10 天。（單次搶劫最多只能拿走淨資產的 40%，所以被重創之後仍有補救空間。）

倒閉畫面統計：經營天數、最高總資產、最大客戶數、股票總損益、遭遇搶劫次數、成功防守次數、被搶總金額、最高等級、最終負債、最終淨資產。
